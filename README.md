## 🚀 Getting Started

### Prerequisites

Before running the application, install:

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration
- Git
- Android emulator or physical Android device

### 1. Clone the Repository

```bash
git clone https://github.com/AhmedJaberAhmed/Meals-Food-App.git
```

### 2. Open the Project

Open **Android Studio**.

Select:

**File → Open → Meals-Food-App**

### 3. Sync Gradle

Allow Android Studio to synchronize the project dependencies.

If required, select:

**File → Sync Project with Gradle Files**

### 4. Run the Application

1. Connect an Android device or start an emulator.
2. Select the application run configuration.
3. Click **Run ▶** in Android Studio.

### 5. Optional: Build from Terminal

On Windows:

```bash
gradlew.bat assembleDebug
```

On macOS/Linux:

```bash
./gradlew assembleDebug
```

The build requires a compatible Android SDK and JDK.
